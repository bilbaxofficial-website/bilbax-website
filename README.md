# Bilbax — Vercel-ready project

This is your landing page, converted from the Shopify Liquid theme into a Next.js project ready for Vercel deployment.

## How to deploy (no coding needed)

1. Create a free account at https://github.com if you don't have one.
2. Create a new repository, upload all these files to it.
3. Go to https://vercel.com, sign up with your GitHub account.
4. Click "Add New Project", select this repository.
5. Click "Deploy" — Vercel auto-detects Next.js and does the rest.
6. You'll get a free live URL like bilbax.vercel.app instantly.
7. Later, attach your bilbax.in domain in Vercel's project Settings → Domains.

## Local testing (optional)
If you want to preview it yourself before deploying:
```
npm install
npm run dev
```
Then open http://localhost:3000
